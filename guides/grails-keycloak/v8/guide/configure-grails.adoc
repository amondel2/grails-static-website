== Configure the Grails Application

This chapter describes how to configure the Grails application to connect to PostgreSQL and Keycloak via environment variables.

=== Database configuration

The application constructs the JDBC URL from environment variables:

[source,text]
----
DB_HOST, DB_PORT, DB_NAME, DB_USERNAME, DB_PASSWORD
----

Example:

[source,text]
----
export DB_HOST=localhost
export DB_PORT=5432
export DB_NAME=example_app
export DB_USERNAME=example_app
export DB_PASSWORD=change-me
----

The resulting JDBC URL is:

```
jdbc:postgresql://${DB_HOST}:${DB_PORT}/${DB_NAME}
```

=== Keycloak configuration

Set the Keycloak OIDC issuer and client credentials via environment variables:

[source,text]
----
export KEYCLOAK_CLIENT_ID=example-client
export KEYCLOAK_CLIENT_SECRET=change-me
export KEYCLOAK_ISSUER=http://localhost:8081/realms/example
----

Keep client secrets out of source control; use environment variables or a secrets manager.
