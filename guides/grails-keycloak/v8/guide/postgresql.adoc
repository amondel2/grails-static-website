== PostgreSQL Setup

This chapter explains creating the databases and users used by the Grails app and Keycloak.

=== Create the Grails database

Connect to PostgreSQL as an administrative user and create the application user and database:

[source,sql]
----
CREATE USER example_app WITH PASSWORD 'change-me';

CREATE DATABASE example_app OWNER example_app;
----

For local development, the connection is typically at `localhost:5432`.

NOTE: Do not use these example credentials in production.

=== Create the Keycloak database or schema

You can either give Keycloak a separate database or a dedicated schema. To create a separate Keycloak database and user:

[source,sql]
----
CREATE USER keycloak WITH PASSWORD 'change-me';
CREATE DATABASE keycloak OWNER keycloak;
----

To use a schema inside an existing database:

[source,sql]
----
-- Connect to the database as postgres
CREATE SCHEMA keycloak AUTHORIZATION keycloak;
GRANT USAGE, CREATE ON SCHEMA keycloak TO keycloak;
----

Keycloak manages its own tables; do not create them manually.
