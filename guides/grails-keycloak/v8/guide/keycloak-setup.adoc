== Configure Keycloak

This chapter summarizes the Keycloak steps required for the example application. See the example repository's `KEYCLOAK.md` for full commands.

* Create a realm (e.g. `example`).
* Create a client for the Grails app and enable `openid-connect`.
* Configure redirect URIs for your app (e.g. `http://localhost:8080/*`).
* Create realm roles: `USER` and `ADMIN`.
* Make `ADMIN` a composite role that includes `USER` so administrators inherit user permissions.
* Configure a client-role mapper so that client-scoped roles are available as realm roles or claims consumed by Spring Security.
* Configure SMTP for email verification and password reset.

=== Environment file for Keycloak (example)

[source,bash]
----
KC_DB=postgres
KC_DB_URL=jdbc:postgresql://localhost:5432/example
KC_DB_SCHEMA=keycloak
KC_DB_USERNAME=keycloak
KC_DB_PASSWORD=<your-keycloak-password>
----

Protect any environment files containing secrets; do not commit them into Git.
