This guide shows how to integrate a Grails 8 application with Keycloak using OpenID Connect for authentication and role-based authorization. It is a documentation-style guide (no sample-app vendoring). Use the example project in `grails-keycloak-example/` as a reference for runnable configuration.

== What you'll need

* Java 21
* Grails 8
* PostgreSQL
* Keycloak 26+


== How to follow this guide

Read each chapter and copy the configuration snippets into your environment. Avoid committing secrets to source control; use environment variables as shown.
