== Run the Application

After databases and Keycloak are configured and environment variables are set, start the Grails app:

[source,bash]
----
./grailsw bootRun
----

Public pages should be accessible without authentication. Accessing protected pages will redirect to Keycloak for login; after successful authentication Keycloak returns the user to the Grails app.

== Testing roles

* Create a Keycloak user with the `USER` role and verify access to user-protected pages.
* Create an `ADMIN` user (which inherits `USER`) and verify access to admin-protected pages.

== Email verification and password reset

Configure SMTP in Keycloak and test email flows (verification and password reset) with a test account.
